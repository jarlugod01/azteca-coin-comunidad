# Glosario

| Término | Significado en la bitácora |
| --- | --- |
| Nodo | Programa que conserva y comprueba una copia del estado de la red. |
| Validador | Nodo que participa en el consenso emitiendo votos. |
| Bloque | Conjunto ordenado de datos que la red propone incorporar a la cadena. |
| Altura | Posición de un bloque en la cadena. |
| Consenso | Proceso por el que los validadores acuerdan qué bloque confirmar. |
| Hash | Huella calculada a partir de datos. Permite comparar dos resultados de manera compacta. |
| Estado de la aplicación | Resultado acumulado de procesar los bloques según las reglas de la aplicación. |
