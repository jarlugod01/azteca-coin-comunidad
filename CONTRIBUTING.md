# Cómo contribuir

Para una duda de lectura o una propuesta editorial, abre una incidencia con la página, la frase y una sugerencia concreta. Para corregir el texto directamente, envía una pull request centrada en un solo cambio.

Explica los términos nuevos en español y enlaza fuentes públicas cuando afirmes que una función existe o que una prueba pasó. Los ejemplos deben usar datos ficticios. Omite datos de cuentas, claves y registros privados. Reserva las incidencias públicas para temas de documentación.
